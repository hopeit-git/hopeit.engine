# Config-manager plugin

This Hopeit app exposes runtime and cluster app configuration through standalone
GET events. The apps visualizer uses its configuration contracts and client.

## Usage

- Include [config/plugin-config.json](config/plugin-config.json) with the app and
  server configs, both when serving and when generating OpenAPI.
- Use `runtime_apps_config` for the running process and `cluster_apps_config` for
  the configured cluster view. See [README.md](README.md) and the plugin's
  [client](src/hopeit/config_manager/client.py) for remote/in-process retrieval.
- Preserve the distinction between declared app events and effective runtime
  events, which include stages generated by SHUFFLE.

## Development

Check runtime and cluster endpoints and their [integration tests](test/integration/)
when changing configuration serialization, host aggregation, or runtime event
discovery. Keep the shared contracts compatible with apps-visualizer consumers.

Run from the repository root:

```sh
make PLUGINFOLDER=plugins/ops/config-manager lint-plugin
make PLUGINFOLDER=plugins/ops/config-manager test-plugin
```
